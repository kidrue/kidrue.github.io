# 本地日记

把 Markdown 文件放进这个目录，网站的「日记」导航（`/diary`）就会读取它们，按年月分组、日期倒序展示。支持按年份创建子目录。日记与文章列表相互独立。

## 最简单的写法

新建 `2026-10-28-今天的记录.md`：

```markdown
# 今天的记录

今天发生了什么，随手记在这里。

- 一个小发现
- 一件值得记住的事
```

日期取文件名开头的 `YYYY-MM-DD`；标题依次取文件头 `title`、正文开头的一级标题、文件名去掉日期的部分。同一天可以有多篇日记，只要文件名不同。

## 可选文件头

也可复制 `_模板.md` 并重新命名。文件头支持：

```markdown
---
title: 今天的记录
date: 2026-10-28
description: 可选的一句简介
tags:
  - 日常
---

正文从这里开始。
```

有 `date` 字段时可以使用任意文件名；日期必须是有效的 `YYYY-MM-DD`。空文件不展示，日期或 YAML 格式错误会在预览中指出文件，不会悄悄漏掉记录。

## 保存与预览

- 开发模式 `npm run dev:web` 下，添加、修改和删除文件后页面会自动更新。
- 已部署的网站读取构建时的内容，修改本地日记后需重新运行 `npm run build:web` 并发布新的前端产物。
- 此目录下的普通 `.md` 会成为公开网页内容；`README.md`、`readme.md`、以 `_` 开头的文件和目录不参与读取，可用于模板或草稿。不要使用 `draft: true`，需要暂不展示时请给文件名加 `_` 前缀。
- 图片可放在 `apps/web/public/images/diary/`，使用 `![说明](/images/diary/图片名.jpg)` 引用；不要使用本机磁盘绝对路径。

说明和模板本身不会显示为日记。
