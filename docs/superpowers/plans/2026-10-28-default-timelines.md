# 文章与追番默认时间轴

用户要求两处首先展示“时间 → 标题”，追番时间轴直接显示图片。

实现：文章按发布日期、番剧按首播日期，均按年月分组倒序排列。文章点击标题沿用阅读弹窗；番剧行内直接显示封面、标题、状态，点击展开评分和观看记录。未明确播出时间的系列保留在末尾。默认使用时间轴，同时保留卡片切换入口；切换不清空搜索或状态筛选。

布局共用 Timeline.styles.ts，使用原生 button、details/summary 支持键盘。手机保持日期在标题左侧，长标题换行，封面缩小显示。

验证包含默认视图、月份与日期排序、行内海报、键盘展开、视图切换、搜索筛选、阅读弹窗和手机无横向溢出。原海报网格测试明确进入卡片视图；分类测试按标题识别名为“2022-07”的文章，避免误匹配新展示的发布日期。
