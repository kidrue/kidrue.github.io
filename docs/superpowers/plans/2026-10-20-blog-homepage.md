# kidrue 博客首页实现计划

> **For agentic workers:** 使用 superpowers:executing-plans 顺序实现，用户已要求执行已批准方案。

**目标：** 交付具备 Miyako 风格、可筛选文章和阅读弹窗的响应式个人博客。

**架构：** Vite 单页项目；文章数据与视觉卡片、阅读弹窗分离；React 管理分类、导航状态，原生 dialog 管理焦点和键盘行为。

**技术：** React、TypeScript、Vite、CSS、Lucide、Playwright。

**设计：** `docs/superpowers/specs/2026-10-20-blog-design.md`

## 全局约束

- 使用原头像与原创 SVG/CSS 几何装饰；中文界面；六篇标注示例文章；不增加后端和发布流程。
- 纸蓝 #f2f7fb，墨蓝 #17324b，青色 #087cba；触控区域至少 44px。

## 重点检查

- 分类变更不得残留前一个分类文章。
- 弹窗关闭须恢复焦点与滚动。
- 移动端导航选择后关闭；折叠时链接不进入 Tab 顺序。
- 窄屏无溢出，减少动态效果时页面仍可用。
- 所有示例文章均可阅读，无无效社交链接。
