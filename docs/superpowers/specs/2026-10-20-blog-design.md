# kidrue 博客首页设计

依据用户批准的对话方案实现技术与生活混合的博客首页。采用 React、TypeScript、Vite，本地六篇示例文章，保留 avatar.jpg 原图。当前按后续需求使用暗色星空入口、头像、kidrue、每日一言及社交链接，内容区保留 Miyako PaperGrid 的几何网格和不对称圆角，并统一为暗色主题与寒蝉全圆体。

文章分类为全部、技术、生活。阅读使用原生 dialog 展示正文，支持按钮、遮罩和 Escape 关闭、焦点恢复及滚动锁定。导航使用锚点，移动端折叠。响应式验收宽度为 390、768、1440px，支持键盘焦点和 reduced-motion。

暂不加入后端、评论、登录、管理后台或部署。不得借用 Miyako 来源站点的品牌、插画或文章资源。

## 兴趣与作品扩展

按用户后续需求，在文章之后、关于之前加入兴趣收藏及开发项目。顶部导航新增收藏与项目两个锚点，保持滚动高亮、移动折叠菜单和自然键盘顺序。

- 兴趣收藏切换看过的动漫、收藏的手办，每类三条示例；卡片显示状态、标题、简介与标签，原生 details 展开观后感或收藏故事。
- 默认使用原创 SVG 示意封面与藏品图；数据支持可选 image 地址，加载失败时回退并显示提示。
- 项目区显示状态、简介、技术栈及可展开开发记录；本站为真实项目，其余两条为示例。只有填写了地址的项目显示链接。
- 每条记录的 example 字段控制示例标记，收藏数量按当前数据计算。真实条目不应被标记为示例。
- 内容仍通过本地数据文件维护，不增加编辑后台、账号或发布流程。
- 番剧区提供「全部、看过、想看、搁置」四个筛选入口，按当前分类展示数量；切换到手办时隐藏番剧状态，切回时保留状态。空分类显示友好提示和查看全部番剧入口。数据通过 AnimeStatus 类型约束三种实际状态，示例分别演示三类。

## 文章浏览完善

文章区支持关键词、分类和标签同时筛选。关键词匹配标题、摘要、标签及正文，去掉首尾空格并忽略英文大小写，特殊字符按普通文本处理。标签从本地文章数据自动生成，数量不写死。

无结果时展示明确提示与查看全部文章入口；可分别清空关键词、重置所有筛选，并恢复输入框焦点。筛选后的文章仍可正常阅读，关闭弹窗后保留筛选条件。搜索和标签控件在移动端纵向排列，继续使用本地寒蝉全圆体。

## 暗色入口与每日一言

- `/` 为独立的一屏入口，只显示头像、kidrue、每日一言、社交链接和「进入博客」按钮；不渲染导航栏、文章、收藏、项目、关于和页脚。按钮进入 `/blog#articles`，博客内容页保留全部板块、移动导航及阅读功能，首页链接返回入口。既有全部板块和阅读弹窗使用暗色表面、浅色正文及青蓝强调。
- 背景使用用户指定的《你的名字。》官网天空素材，原图保存在 public/images，CSS 叠加流星光轨与暗色遮罩，入口提供来源链接；动效服从 reduced-motion。
- 一言使用官方 v1 HTTPS JSON 接口，保留文本、作者与出处，并指向一言详情。按访客本地日期缓存，同日刷新复用；跨午夜及页面恢复时检查日期。失败显示标注寄语和重试，缓存不可用不阻断阅读。
- 未增加后端任务或密钥；测试固定 API 边界以验证每日更新语义、异常响应与缓存恢复，避免对公共接口产生并发请求。

## 入口图标与起飞按钮

- 社交入口使用平台官网提供的 Bilibili、GitHub、V2EX 图标，素材本地保存，保留原始品牌颜色。
- 进入博客参考用户指定的纸飞机按钮交互，使用冰蓝纸面与深蓝折面，约 1.2 秒内折叠、起飞并进入博客；保持一屏展示。
- 使用 CSS 动画与 React 状态实现，不增加动画依赖。支持键盘 Enter、修饰键与中键新标签导航、减少动态效果直接跳转、动画事件失效时超时跳转，以及浏览器返回入口后的再次进入。

## 循环流星背景

- 原始天空图本身没有流星，保留原文件；移除原先仅闪烁、位置固定的两条 CSS 光轨。
- 使用二十道错峰循环流星，从右上向左下移动，具有不同起点、长度、速度、淡入和淡出。新增流星采用更短周期，提高同时出现的数量与整体出现频率。中央区域减弱亮度，确保头像、名言和入口按钮清晰。
- 装饰层不接收指针事件、不进入无障碍树，使用 transform 与 opacity 动画。保持入口一屏布局，手机缩短拖尾，减少动态效果时隐藏全部流星并显示干净天空。
