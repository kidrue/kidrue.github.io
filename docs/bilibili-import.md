## 更新

```sh
npm run import:bilibili
npm run build:pages
```

导入命令通过无需登录的公开接口 `https://api.bilibili.com/x/space/bangumi/follow/list` 分页读取账号 `25857856` 的番剧收藏（`type=1`、`follow_status=0`、每页 30 条），按 `season_id` 去重。读取失败、分页不完整或封面下载失败时不会替换已有快照。提交更新到 `main` 后由 GitHub Actions 自动部署。

接口需要登录或不可用时，应保留旧快照，不保存登录凭据、不用错误页覆盖数据。默认每次运行更新列表与状态，已有本地封面复用。

## 日期和状态

新记录的日期使用接口 `publish.release_date`，不使用追番操作日期或最新集更新时间。这是 Bilibili 提供的上映日期，部分作品可能采用地区上映日期，因此页面也说明了来源差异。已核对的旧记录继续使用原首播日期。

尚未开播（`is_started=0`）或日期无效的条目放入“播出时间待确认”。例如“李诗雅”的接口日期为远期占位值，不当作已播出时间使用。平台状态 1/2/3 分别对应想看/在看/看过，不根据作品是否完结推测个人是否看完，也不把平台评分当作个人评分。
