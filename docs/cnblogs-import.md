# 博客园 Markdown 归档

来源：[kidrue 的博客园](https://www.cnblogs.com/Kidrue)。本次收录全部可公开访问的 16 篇随笔和 1 篇文章，共 17 篇；范围为 2021-04-30 至 2022-12-30。其中《git 的基础使用》来自独立文章归档，未遗漏在首页分页之外的内容。

## 文件与元数据

- 正文：`apps/web/src/content/posts/YYYY-MM-DD-原站ID.md`。
- 图片：`apps/web/public/images/posts/cnblogs/`，7 张图片按内容摘要命名，同一张图片可被多处引用。
- 清单：`docs/cnblogs-import.json`，记录每篇原文地址、原始时间、分类、文件路径、图片来源及本次导入时间。
- 转换脚本：`scripts/import-cnblogs.mjs`。原始页面和分类响应在运行脚本时留于忽略提交的 `artifacts/cnblogs-source/`，便于核对。

Markdown 顶部使用 YAML front matter：

| 字段                                  | 含义                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------ |
| `id`                                  | `cnblogs-原站ID`，避免与后台文章 ID 冲突                                 |
| `title` / `author`                    | 原始标题与作者                                                           |
| `date`                                | 原站发布日期，供卡片展示                                                 |
| `createdAt`                           | 原站正文 `#post-date` 显示的首次发布时间，精确到分钟，使用 `+08:00` 时区 |
| `updatedAt`                           | 原站 `data-date-updated` 提供的最后更新时间；缺失时不编造                |
| `category`                            | 本站筛选分类：追番记录映射为「生活」，其余为「技术」                     |
| `tags`                                | 原站分类与原站标签的并集，供本站筛选                                     |
| `sourceCategories` / `sourceTags`     | 分别保留原站分类与标签，未设置则为空数组                                 |
| `source` / `sourceUrl` / `sourceType` | 平台、原文链接及随笔/文章类型                                            |
| `description`                         | 从正文提取的列表摘要                                                     |

这里的「创建时间」指原站公开展示的首次发布时间；公开页面不提供首次起草时间。部分原站结构化数据中的 `datePublished` 实际等于更新时间，因此不采用该字段替代正文发布时间。

## 内容保留与转换

从公开页面的 `#cnblogs_post_body` 提取完整正文，转为 Markdown，保留原文措辞、代码、列表、链接和图片；不迁入评论、广告、阅读计数或平台操作栏。使用公开渲染后的 HTML 转换，不声称获得作者后台的原始 Markdown 源文件。

早期 Vue 示例中的 `<template>`、`<router-link>` 和复制按钮模板转为 HTML 代码块，避免被安全渲染器过滤。其中的示例资源路径（如 `../assets/logo.png`）保留在代码中，不作为正文图片下载。原文已有的拼写、代码写法和技术观点不做改写。

实际正文图片全部下载到本地，原始图片地址与本地路径保留在清单中。前端自动读取 `.md`，按创建时间倒序展示，与后台已发布文章合并；本地文章不写入服务端数据库，也不出现在后台编辑器的文章列表中。

## 再次导入

```sh
node scripts/import-cnblogs.mjs
```

脚本检查原站随笔与文章总数、首页分页和独立文章归档，数量不一致或正文/图片下载失败时退出。再次执行会覆盖同名 Markdown 文件，请先保存对归档文件的手动修改。私有文章、草稿或已删除内容不在公开下载范围内。
