# 顶部导航与加载优化

公开页面使用 React Router 7.18.5 Data Router，兼容项目当前 Node.js 22.14 和 React 19。导航使用真实 URL，普通点击在当前文档内切换；直接访问、刷新、组合键打开新标签、浏览器前进后退仍可使用。

## 加载策略

- 页面 loader 加载目标模块，和悬停、聚焦、触摸时的预取共用同一个 Promise，避免重复请求。
- 切换过程中保留公共导航、页脚和当前内容，主内容标记忙碌状态，导航底部显示进度；加载失败提供重新加载页面的入口，也可继续选择其他栏目。
- 公共页面空闲时预取日记和项目。省流量、2G/慢速 2G、后台标签页不主动预取；点击目标栏目仍正常加载。
- 首页纸飞机动画期间预加载文章页。静态站点不加载写作工作台，也不请求文章 API。
- 正文 Markdown 渲染器延迟到阅读时加载，文章标题悬停和聚焦时提前预热。弹窗先展示标题和加载提示，正文到达后显示；失败可重新加载页面。

项目页继续使用 `/projects`，其他公开地址和 GitHub Pages 的独立 index.html 保留。旧 `/blog#collections`、`/blog#projects` 在站内替换为对应独立页面。

## 浏览状态

文章的搜索、分类、标签、视图，以及兴趣页的收藏分类、观看状态、视图存入内存缓存。跨栏目返回时恢复，刷新后重置；页面离开后卸载，不长期隐藏保留整套番剧 DOM。

滚动位置分别按历史条目和导航目标记录。前进后退优先恢复历史条目位置；跨栏目重访恢复该目标上次位置；同一博客页内点击文章、一句话、关于时定位锚点。首次访问或刷新按 URL 锚点定位，等待页面和字体就绪后调整；期间若用户已经滚动或操作，则取消迟到的补偿定位。跨页切换完成后焦点移至主内容，同页内容跳转也移交键盘焦点，使跳过导航链接可用。

写作工作台保持独立文档导航，避免将草稿、上传和登录会话放入公开页面缓存。没有新增后端接口。

## 验证方式

先运行 `npm run build:pages` 和 `npm run preview`，再运行 `npm run measure:navigation`。也可使用 `node scripts/measure-navigation.mjs http://127.0.0.1:4173 artifacts/navigation-after.json` 指定地址和报告文件。报告保存在忽略的 `artifacts/` 目录，包含原始样本、统计值、额外文档请求和 API 请求数量。

浏览器回归覆盖文档和公共导航复用、状态和位置恢复、前进后退、锚点、预取去重、慢加载、快速连续切换、加载失败、省流量模式，以及正文渲染器按需加载。另运行现有文章、日记、兴趣、项目和编辑器测试及静态构建。

性能测量使用本机 Chrome 和 Vite preview 的生产产物，桌面 1440px、手机宽度 390px，各 3 个全新浏览器上下文；先打开博客并等待字体，然后依次切换兴趣、项目、文章、兴趣、项目。测量点击到目标内容可用并完成下一帧的耗时，分别统计首次进入和重复进入；同时记录 HTML 文档及 API 请求。

这是相同本机环境的前后对比，不代表公网或所有设备的加载时间。优化后的首包增加了路由框架代码，主要收益来自后续导航复用文档与已加载模块。

2026-10-29 本机生产构建测量（毫秒，中位数）：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 桌面 1440px 首次进入 | 568.5 | 148 |
| 桌面 1440px 重复进入 | 471 | 53 |
| 390px 宽度首次进入 | 564 | 122.5 |
| 390px 宽度重复进入 | 459 | 44 |

每轮 5 次切换的额外 HTML 请求从 5 次降至 0 次，优化后 6 轮静态浏览的 API 请求均为 0。首包 gzip 从约 100.36KB 增至 134.44KB；正文渲染器约 160.76KB（gzip 49.18KB）从列表加载路径中拆出。

实现选择：使用兼容现有 Node.js 的 React Router 7，增加框架依赖；通过少量 loader 与 React.lazy 适配代码稳定处理模块加载失败。受限网络的正文预热也复用网络守卫，以减少后台下载，代价是首次主动阅读时再请求正文代码。

最终功能回归为 139 项通过、3 项按条件跳过，22 项构建工具检查通过，静态构建通过。独立整体审查复现的慢字体位置覆盖、跳过导航焦点和受限网络正文预热问题均已补充失败用例并修复。

补充的全站 axe 扫描仍报告两项既有问题：阅读正文代码块的横向滚动区域缺少键盘焦点，以及番剧年月分组列表的语义。对应 DOM 结构在基线 `0b354cc` 已存在；入口、博客首页、手办详情、独立项目详情和搜索无结果状态未报告违规。全站无障碍扫描不能视作全部通过。
