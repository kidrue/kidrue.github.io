边框是围绕在div等元素外层的结构之一。  
border颜色默认为黑色。  
border-radio可以控制边框的圆角属性。  
border按照顺序为以下属性：  
border-width；（宽度）border-style；（边框的类型）border-color；（边框颜色）  
transparent控制边框为透明

border-style可能的值：

| 值 | 描述 |
| --- | --- |
| none | 与 “none” 相同。不过应用于表时除外，对于表，hidden 用于解决边框冲突。 |
| dotted | 定义点状边框。在大多数浏览器中呈现为实线。 |
| dashed | 定义虚线。在大多数浏览器中呈现为实线。 |
| solid | 定义实线 |
| double | 定义双线。双线的宽度等于 border-width 的值。。 |
| groove | 定义 3D 凹槽边框。其效果取决于 border-color 的值。 |
| ridge | 定义 3D 垄状边框。其效果取决于 border-color 的值。 |
| inset | 定定义 3D inset 边框。其效果取决于 border-color 的值。 |
| outset | 定义 3D outset 边框。其效果取决于 border-color 的值。 |
| inherit | 规定应该从父元素继承边框样式。 |
