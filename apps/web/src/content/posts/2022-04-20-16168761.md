1.  首先克隆一份代码下来（默认main分支）  
    `git clone https://github.com/kidrue/gittest.git`
2.  创建并切换分支开始工作（分支相当于一个独立的版本，以创建分支时的为版本保存新分支）  
    `git checkout -b dev` 创建并切换到dev分支  
    `git push --set-upstream origin dev` 设置代码上游分支，并在远程仓库创建dev分支  
    上述命令类比于以下两行  
    `git branch dev`  
    `git checkout dev`  
    `git checkout` 命令切换分支时会修改本地工作空间，而 `git switch` 不会
3.  工作完成后首先拉取远程仓库代码，然后进行推送本地代码至远程仓库  
    `git pull //冲突应当在此处解决` 拉取代码  
    `git add .` 将修改代码提交缓存区，可通过`git status`查看  
    `git commit -m '初次提交工作代码'` 代码并附带描述提交至本地仓库  
    `git push` 代码推送至远程仓库
4.  切换主分支，并合并代码  
    `git checkout main` 切换至main分支  
    `git merge dev`合并dev分支  
    `git push`  
    `git pull`
