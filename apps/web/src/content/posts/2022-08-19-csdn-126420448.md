#### _您正在编写代码并决定在未来添加一项功能。_

| 措辞 | 表示 |
| --- | --- |
| FIXME： | 东西坏了/（something is broken） |
| HACK/OPTIMIZE: | 代码不是最理想的应该重构/（the code is suboptimal and should be refactored） |
| BUG： | 代码中有一个错误/（there is a bug in the code） |
| CHECKME/REVIEW: | 代码需要审查/（the code needs to be reviewed） |
| DOCME： | 需要记录代码（在代码库或外部文档中）/(the code needs to be documented (either in codebase or external documentation)) |
| TESTME： | 需要测试指定的代码，或者需要为选择的代码编写测试/ (the specified code needs to be tested or that tests need to be written for that selection of code) |
