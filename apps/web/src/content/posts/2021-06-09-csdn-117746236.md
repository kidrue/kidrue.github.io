后台运行bootMP-0.0.1-SNAPSHOT.jar包

```powershell
nohup java -jar bootMP-0.0.1-SNAPSHOT.jar > nohup-boot.out 2>&1&
```

关闭进程pid 6586

```powershell
kill -9 6586
```

查看nohup-boot.out日志文件

```powershell
tail -f nohup-boot.out
```

查看当前目录下所有文件

```powershell
ls
```

查看当前jar运行服务

```powershell
ps -ef|grep java
```

查看当前所有运行服务

```powershell
ps aux | less
```

进入jingyushuo数据库

```powershell
mysql -u root -p jingyushuo
```

mysql大小写需要在my.cnf文件配置 （my.cnf通常在etc目录下）

```powershell
lower_case_table_names=1
```

mysql重启命令

```powershell
service mysqld restart
```

.linux查看版本当前操作系统发行信息

```powershell
cat /etc/centos-release
```
