首先安装号node.js  
安装淘宝 NPM 镜像

```powershell
$  npm  install  -g  cnpm  --registry=https://registry.npm.taobao.org
```

项目初始化

```powershell
cnpm install vue-cli -g//全局安装 vue-cli
```

查看安装好的版本号

```powershell
vue list//查看vue版本号
```

![在这里插入图片描述](/images/posts/csdn/415d586db47d164b.png)

创建项目名称

```powershell
vue init webpack  ”项目名称“
```

![在这里插入图片描述](/images/posts/csdn/b7ec88bb78622029.png)  
项目模块安装 npm install 或 cnpm install

运行项目 npm run dev
