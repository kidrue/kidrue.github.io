管理员Wt执行以下命令：

```bash
netsh interface portproxy add v4tov4 listenport=[转发宿主机对应端口] listenaddress=0.0.0.0 connectport=[wsl2中需要转发的端口] connectaddress=[wsl2内服务ip地址]
```

> eg: `netsh interface portproxy add v4tov4 listenport=5273 listenaddress=0.0.0.0 connectport=5273 connectaddress=172.20.142.7`

## 以下命令用于补充用法：

---

1. 查看当前所有转发服务

   ```bash
   netsh interface portproxy show all
   ```

2. wsl2中查看当前分配地址

   ```bash
   ip a
   ```
