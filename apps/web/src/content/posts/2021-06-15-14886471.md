结论：  
query方式：传参数是会显示在地址栏，必须使用key-value传参，刷新时不会丢失参数，但参数会被全部转换为字符串格式。（当没有传key值时，跳转路由后无法接收参数）

params方式：传参数是不会显示在地址栏，也不用以key-value的方式传参，刷新后会丢失参数。（当没有传key值时，默认以传参时参数名为key）

代码：\`  
data() {  
return {  
status: "params-1",  
status2: "params-2",  
status3: "query-1"  
}  
},  

```html
<router-link :to="{ name:'home',params: { id: status ,id2: status2},query: { queryId:  status3 }}"><br>
router-link跳转router1<br>
</router-link>
```

```html
<template>
  <div class="home">
    <img alt="Vue logo" src="../assets/logo.png">
   <h1> params.id：{{ $route.params }}</h1>
    <h1>query.status:{{ $route.query.queryId }}</h1>
  </div>
</template>
```
