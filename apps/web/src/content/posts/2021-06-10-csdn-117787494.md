### 首先安装好node.js环境和vue-cli

```powershell
//卸载当前vue-cli
npm uninstall vue-cli -g
```

```powershell
//查看当前vue-cli版本
vue -V
```

```powershell
//安装vue-cli
npm uninstall vue-cli -g
```

vue-cli版本 为3以下时 无法唤起创建界面

```powershell
vue ui
```

安装eslinter时使用该命令自动修正格式

npm run lint
